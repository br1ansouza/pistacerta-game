# PistaCerta

Jogo de adivinhação de veículos ("Qual é o carro?"): o sistema escolhe um veículo secreto, revela pistas progressivamente (ano, preço FIPE, combustível, cilindrada, potência...) e o jogador tenta descobrir qual é antes de esgotar as pistas.

Foco inicial: carros com relevância real no mercado/cultura automotiva brasileira. Arquitetura pensada desde o início para permitir expansão futura para motocicletas.

🚧 Em desenvolvimento — ainda sem primeira versão jogável.
